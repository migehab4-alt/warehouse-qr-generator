Task 2: Monthly Sales, Off-Plan vs. Existing Properties

Number of sales registered per month at the Dubai Land Department, shown separately for off-plan properties and existing properties, from 1 January 2015 to 31 August 2026 (both included). Only transactions whose group is Sales are counted. Months are computed in UTC, so the chart looks the same in every time zone. Months with no sales are drawn as 0 instead of being skipped.

Question: In which month is the number of off-plan sales the highest, and how many off-plan sales is it?

How to read the chart

The horizontal axis shows the months (labels mark January of each year) and the vertical axis shows the number of registered sales in that month. The orange line is off-plan properties and the blue line is existing properties. The red point with a label marks the month with the highest off-plan sales. Hover over any point to see the month, the property type and the exact number of sales.

Data source and method

Data: Dubai Land Department transactions, loaded directly by Vega-Lite from the course CSV on GitHub.

  1. Date type: instance_date is parsed as a UTC date, so a month never changes with the viewer's time zone.
  2. Window: only dates from 1 January 2015 up to and including 31 August 2026.
  3. Sales only: only rows where trans_group_en is Sales.
  4. Two categories: reg_type_en separates Off-Plan Properties from Existing Properties; other values are ignored.
  5. Monthly count: each qualifying row adds one sale to its UTC month and category.
  6. Missing months: a month with no sales is added with a count of 0 for each category (impute), so the lines cover all 140 months without gaps.
  7. Peak: the highest off-plan month is found from the monthly counts, highlighted on the chart and written in the answer box above.
